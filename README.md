# CHI PLAY Co-authorship Explorer

Interactive co-authorship network of CHI PLAY full papers, 2014–2025, built for
"Three Fun Facts About CHI PLAY (And One Slightly More Serious Observation)",
CHI PLAY Companion '26 — https://doi.org/10.1145/3800965.3834665

Live: https://jamescfey.github.io/chiplay-explorer/

A work in progress: author names were extracted automatically from the proceedings PDFs,
so expect the odd edge case. 2026 papers will be added once their DOIs resolve.
